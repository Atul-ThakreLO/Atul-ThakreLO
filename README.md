## About Me

I'm a final-year B.Tech student in Computer Science (AI & ML) at YCCE, Nagpur. I build full-stack web applications and care about what happens after the code is written: how a system is structured, containerized, deployed, and kept running.

My recent work centers on microservices and Kubernetes on AWS EKS. I also have earlier experience building Web3 applications.

I'm the Working Chairperson of the ACM CSE Student Chapter and am looking for **SDE and full-stack engineering roles**.
